Duas provas inteiras, como no dia do vestibular. Cada uma tem um tema transversal que amarra todas as matérias, três cadernos de conhecimentos, itens dos tipos A, B, C e D e uma proposta de redação. Separe 5 horas, desligue o celular e faça de uma vez.

Tipo A (certo/errado): acerto +1, erro −1 Tipo B (numérico) e tipo C (múltipla escolha): acerto +1, erro 0 Tipo D (discursiva): resposta-modelo para autocorreção

Neste site, os itens tipo B e C não descontam quando errados. No vestibular, confira no edital a pontuação de cada tipo de item. Textos e itens foram escritos para este site.
